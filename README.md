# Meu Portfólio

Portfólio pessoal desenvolvido com HTML5, CSS3 e JavaScript puro.

## Estrutura

- `index.html`: conteúdo e estrutura do site.
- `css/style.css`: estilos, layout e regras responsivas.
- `js/script.js`: menu mobile, animações de entrada, ano automático e navegação.
- `imagens/`: imagens utilizadas no projeto.

## Como executar no VS Code

1. Extraia a pasta `meu-portfolio`.
2. Abra o VS Code e selecione **Arquivo > Abrir Pasta**.
3. Escolha a pasta `meu-portfolio`.
4. Abra o arquivo `index.html`.
5. Clique com o botão direito e selecione **Open with Live Server** (se a extensão Live Server estiver instalada).
6. Se não tiver Live Server, abra o `index.html` diretamente no navegador.

## Personalização antes de publicar

- Coloque sua foto em `imagens/perfil.jpg`.
- Atualize os links do GitHub e LinkedIn no `index.html`.
- Troque `seuemail@exemplo.com` pelo seu e-mail.
- Atualize os projetos e os links dos repositórios para apontarem para seus trabalhos reais.
- Revise as informações pessoais para garantir que estejam corretas.

## Publicar no GitHub Pages

1. Crie um repositório público chamado `meu-portfolio` no GitHub.
2. Envie todos os arquivos e pastas deste projeto para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O endereço será semelhante a `https://SEU-USUARIO.github.io/meu-portfolio/`.

> O arquivo `index.html` precisa permanecer na raiz do repositório para o GitHub Pages localizar a página inicial.
